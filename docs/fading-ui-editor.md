> 用途：把 `public/fading_ui/` 里 244 张原版 UI 纹理在网页上**肉眼拼接**成目标画面，
> 精确定位后导出 JSON / CSS，不再靠截图和文字描述来回猜坐标。
> 入口：`http://localhost:5273/game/fadingaffection/editor`（**仅 dev 环境有此路由**）

## 2. 界面与操作

| 区域 | 功能 |
|---|---|
| 左侧素材库 | 244 张 PNG（按文件名前缀自动分组：底板 / 装饰 / 图标 / 文字印章…）。搜索框支持 `bg_choice`、`deco`、`hp` 等关键字。悬停显示原作填充方式：九宫格 border 数值或平铺。**拖到画布**或点击添加到画布中央；带 border 的素材自动用 `sliced`，平铺类自动用 `tiled`。 |
| 中间画布 | 拖动图层移动；八个控制点缩放（**按住 Shift 等比缩放**，整组也一样）；顶部 `⟳` 旋转（按 Shift 吸附 15°）。**文字图层双击**可直接在画布上编辑，Esc / Ctrl+Enter / 点空白处结束。**按住空格拖动**（或中键拖动）平移整块画布；**Ctrl + 滚轮**以鼠标位置为锚点缩放；工具栏「适应」复位。 |
| 右侧图层树 | 按组折叠展示；**拖动图层行**调整层级（z-index）；拖到**组标题行**上即加入该组，拖到图层列表下方的「⇱ 拖到此处 = 移出组」区即移出组；拖到另一图层上会同时排序并并入目标所在的组。支持 Ctrl+多选一起拖。眼睛 / 锁图标控制显隐与锁定。面板顶部「＋编组 / 解组」按钮（或 Ctrl+G）成组；多选后可一起删除/复制/对齐/调层级。图层列表与属性面板之间的**分隔条可上下拖动**。 |
| 右侧属性 | 精确输入 X / Y / 宽 / 高 / 旋转 / 圆角 / 透明度 / 混合模式；图片可换素材、填充方式（**拉伸 / contain / cover / 九宫格 sliced / 平铺 tiled**）、九宫格 border（左/下/右/上）、灰度、亮度；文字可改内容 / 字号 / 颜色 / 字距 / 阴影。 |
| 顶部「变换」开关 | 选中图片后出现「自由 / .9 图」切换。`.9 图` 模式下图层内显示四条橙色切线，**直接拖动手柄调整九宫格 border**；`自由` 模式恢复八个缩放角点。 |

### 九宫格（.9 图）/ 平铺

**核心规则：有 border 的素材一律按九宫格处理，绝不整张按网格平铺。**
四角与边缘保持原样，只有中间那块被拉伸（`marian_bg_paper` 的 border 是 20/20/20/20，
`marian_bg_book` 是 47/81/70/101，`marian_bg_choice` 是 49/0/73/0）。
border 数值来自 bundle 里的 Sprite 子资源，由 `export_fading_ui.py` 导出到
`build/fading_ui_sprites.json`，Vite 插件合并进素材清单。详见
`docs/fading-ui-sprite-metadata.md`。

- `sliced`：CSS `border-image`，Unity 的「左下右上」换算成 CSS 的「上右下左」，四角固定、中间拉伸——即 .9 图行为。
- **边宽倍率**：属性面板里可调。源图（如 `marian_bg_book` 512×512，border 47/81/70/101）直接按源像素绘制时四边会很粗；倍率 `< 1` 会把绘制宽度收细，同时 `border-image-slice` 仍取完整源图四角，所以纹样不会丢。点「按图层自适应」会按 `min(图层宽/源宽, 图层高/源高)` 自动算出倍率——把图层缩小后就不再显得边粗。橙色切线显示的是缩放后的绘制宽度，拖动时按倍率反算回源像素。
- `tiled`：只用于**零 border 的无缝纹理**（木纹 `marian_ptn_wood_*`、噪波 `marian_texture_paper`、分隔笔刷等），渲染为 `background-repeat: repeat`。
- 没有 border 的素材若手动选 `sliced`，会退化为纯拉伸，不会变成空白。
- 旧存档会在清单加载后自动迁移：带 border 却存成 `tiled` 的图层会改回 `sliced`。
- **调九宫格更直观的方式**：选中带 border 的图片，顶部切到「.9 图」，拖图层内的橙色切线即可改左/右/上/下 border，切线位置与数值标签实时跟着动；属性面板里的四个数字也会同步更新。切回「自由」即可继续用角点缩放图层。

### 图层关系（编组）

- **新建组**：在图层面板按住 `Ctrl` 左键选中多个图层 → 点面板顶部「＋编组」（或 `Ctrl+G`）→ 输入组名。
- 单选时也可以在属性面板的「所属组」填相同名字（例如 `页眉`、`选项`、`状态栏`）来编组。
- **选中整组**：点击图层面板的组名（📁），画布上出现整组虚线包围盒，带 8 个缩放手柄和 `⟳` 旋转手柄；包围盒中心的**十字标记就是旋转支点**（包围盒几何中心），旋转时组内每个图层绕该点公转并自转。单图层的选择手柄会隐藏。按 `Alt` 拖组内某一层仍可单独移动。
- 选中组时右侧属性面板切换为**组属性**：组名（可直接改名）、组内图层数、包围盒 X/Y/宽/高（直接输入即整体平移/缩放），以及复制整组 / 解散组 / 删除整组。
- 不选中整组时，**拖动组内任意图层，整组一起移动**；按住 `Alt` 拖动可临时单独移动某一层。
- 组标题支持：折叠/展开、选中首层、**复制整组**、**解散组**（图层保留）、**删除整组**。
- 顶部「对齐」按钮把**选中层或整组包围盒**对齐到画布的左 / 水平居中 / 右 / 上 / 垂直居中 / 下。
- 右侧「置底 / 下移 / 上移 / 置顶」调整单层的 z 顺序；图层面板拖动行也能调。

### 对齐与吸附

- **网格吸附**：坐标按「步长」（默认 10px）取整，移动和缩放都生效。
- **智能吸附**：拖动时自动把活动框的边 / 中心贴到其它图层的边 / 中心以及画布边缘 / 中线，
  并显示红色参考线。阈值约 7 屏幕像素，缩放后自动换算。
- 两者可同时开启；智能吸附优先级更高。关掉「网格吸附」可获得亚像素自由定位。

### 撤销 / 重做

- 工具栏按钮或 `Ctrl+Z` / `Ctrl+Shift+Z`（也支持 `Ctrl+Y`）。
- 最多保留 120 步；拖拽整段算一步；属性输入每次改动算一步。
- 画布改动自动写入 `localStorage`（`nikke_fading_ui_autosave_v1`），刷新页面不丢。

### 其它快捷键

`方向键` 微调 1px（`Shift` 10px，多选时一起移动）、`Delete` 删除选中（含多选）、
`Ctrl+D` 复制选中（多份副本自动成组）、`Ctrl+G` 编组、`Esc` 取消选中、
`图层面板 Ctrl+左键` 多选、`空格 + 拖动` 平移画布、`中键拖动` 平移画布、`Ctrl + 滚轮` 缩放画布、`Shift + 拖缩放手柄` 等比缩放、`双击文字图层` 就地编辑。

## 3. 保存与导出

| 按钮 | 行为 |
|---|---|
| 本地存档 | 浏览器 `localStorage` 里的命名快照（key `nikke_fading_ui_slots_v1`）。 |
| 存到项目 | POST `/api/fading-layout` → 写入 `build/fading_ui_layout.json`（入库，换机器不丢）。 |
| 从项目读 | GET 同一文件并载入画布。文件不存在时给出提示。 |
| 导出 JSON | 完整布局（画布 + 所有图层的精确数值），可再次「导入」或发给助手还原。 |
| 导出 CSS | 生成 `.fadui-stage` + 每个可见图层的绝对定位规则，可直接贴进 `web/src/pages/fading.css`；`sliced` 输出带倍率的 `border-image` 与 `border-width`、`tiled` 输出 `background-repeat: repeat`。文字内容在 JSON 的 `text` 字段里对照填写。 |

素材清单由 Vite 插件在开发服务器启动时扫描 `public/fading_ui/` 生成到
`public/data/fading_ui_manifest.json`（含每张图的原始宽高，拖入时按原尺寸等比缩小）。
新增 / 删除 PNG 后会自动重建清单并刷新页面。

## 4. 文件清单

| 文件 | 作用 |
|---|---|
| `web/src/pages/FadingUiEditor.tsx` | 编辑器主体（画布、拖拽、编组、吸附、撤销、导入导出） |

### 「↺ 骨架模板」按钮是什么

位于左侧素材库底部。点击后载入一份**按你提供的原截图比例预摆好的剧情页脚手架**（约 28 个图层：纸张、夹子、徽章、藤蔓、标题条、正文、选项条、底部状态栏、ACCESS DENIED、弹孔…），并已分好组。

用途：不用从空白画布开始逐张拖素材、记坐标，直接在骨架上微调即可。点击时会弹窗确认；被替换的旧布局会进入撤销历史，可用 `Ctrl+Z` 找回。
| `web/vite.config.ts` | `fadingUiManifestPlugin`（素材清单 + 合并 Sprite border）+ `fadingLayoutPlugin`（布局落盘 API） |
| `build/fading_ui_sprites.json` | `export_fading_ui.py` 导出的 Sprite 九宫格元数据（236 项） |
| `web/src/App.tsx` | dev-only 路由 |
| `web/src/pages/FadingAffection.tsx` | dev-only 入口链接 |
| `build/fading_ui_layout.json` | 「存到项目」生成的布局文件（首次保存后出现） |

## 5. 典型流程

1. 打开编辑器 → 若想从截图还原，先点「↺ 骨架」得到分层脚手架。
2. 从素材库拖入缺失的碎片（如弹孔、藤蔓、Checked 印章、状态图标），
   用「所属组」把它们归入对应分组。
3. 打开「智能吸附」+「网格吸附」，拖动拼齐；用方向键做最后 1px 微调。
4. 点「预览」隐藏控制点，和原图对照。
5. 满意后「存到项目」+「导出 JSON」把文件发我，我按导出的精确坐标 / 尺寸改 `fading.css`。
